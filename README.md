# Branch-Office-IP-Plan
## Project Overview

A company is opening a new branch office requiring separate networks for Sales, Engineering, and Guest users.
Each department has different host requirements :

| Department  | Required Hosts |
| ----------  | -------------- |
| Sales       | 50             |
| Engineering | 25             |
| Guest       | 100            |
The objective is to design an IPv4 addressing plan using VLSM that provides sufficient host capacity while minimizing wasted address space.

## Objectives
- Design a VLSM addressing plan.
- Prevent subnet overlap.
- Allocate address space based on department requirements.
- Configure the network in Cisco Packet Tracer.
- Assign IP addresses and default gateways.
- Verify connectivity.
- Document the final addressing scheme.
